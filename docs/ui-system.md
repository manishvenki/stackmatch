# StackMatch — Neutral Minimal Design System

## Palette Overview

StackMatch follows a strictly curated **Neutral Minimal** color system to maintain calm, professional visual clarity.

### Primary Color Tokens
- **Deep Dark:** `#111827` (Primary text, dark CTA buttons, accent headers)
- **Slate:** `#374151` (Secondary body copy, headers, active states)
- **Muted Slate:** `#687280` (Supporting metadata, captions, subtitles)
- **Gray:** `#9CA3AF` (Placeholders, inactive borders, icons)
- **Border:** `#D1D5DB` / `#E5E7EB` (Clean 1px dividers, card strokes)
- **Soft Background:** `#F9FAFB` (Subtle off-white application surface)
- **White:** `#FFFFFF` (Card surfaces, dialog sheets, input containers)

### Semantic Colors (Used Sparingly for State)
- **Success:** `#16A34A` (Completed roadmap milestones, valid checks)
- **Warning:** `#D97706` (Medium priority tags, cautionary metrics)
- **Danger:** `#DC2626` (High priority alerts, error badges)
- **Information:** `#2563EB` (Documentation links, informational notes)

---

## Typography Hierarchy
- **Font Family:** `Inter`, system sans-serif fallback
- **Large Hero:** 48–64px desktop
- **Page Heading:** 32–40px
- **Section Heading:** 24–28px
- **Card Heading:** 16–20px
- **Body Text:** 14–16px
- **Secondary Text:** 13–14px
- **Metadata / Chips:** 11–12px

---

## Component Philosophy
1. **White surfaces with thin borders:** Avoid floating elements without clear separation.
2. **Subtle shadows:** Use `shadow-subtle` and `shadow-card` rather than aggressive blurs.
3. **No generic AI purple gradients or neon gaming aesthetics.**
4. **Lucide outline icons:** Clean, consistent line-weight communicate function directly.
